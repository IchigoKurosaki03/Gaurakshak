# Contributing to GauRakshak

## Branches
- `main` — stable
- `develop` — integration
- `feature/...` — individual work

Examples:
- `feature/flutter-dashboard`
- `feature/cow-api`
- `feature/xgboost-model`
- `feature/esp32-sensor`

## Workflow
1. Pull latest `develop`
2. Create feature branch
3. Make small commits
4. Push branch
5. Open Pull Request
6. Review
7. Merge

## Commit examples
- `feat: add cow registration screen`
- `feat: add prediction endpoint`
- `fix: correct cow session mapping`
- `docs: update API specification`

Never commit secrets, API keys, passwords or `.env` files.
