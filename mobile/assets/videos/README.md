# Splash video

Place an original, muted MP4 at this exact path:

`mobile/assets/videos/splash.mp4`

Recommended: 4-6 seconds, portrait (1080x1920), H.264 video, no embedded text
or audio. Run `flutter pub get` and restart the app after adding or replacing
the file. GauRakshak keeps its accessible illustrated splash fallback when no
video is present.
